Course Overview

Course Learning Outcomes (CLOs)

CLOStatement
CLO 1 Understand the fundamental concepts, paradigms, and theoretical foundations of machine learning
CLO 2 Analyze and compare different machine learning algorithms for supervised and unsupervised learning
CLO 3 Explain the mathematical principles (optimization, probability, statistical inference) underlying learning algorithms
CLO 4 Apply machine learning techniques to solve real-world problems and evaluate model performance
CLO 5 Design and implement end-to-end machine learning pipelines for practical applications

About This Course

An OBE-structured 13-week course covering the machine learning canon — from the learning problem and its mathematical foundations, through supervised learning (linear and logistic regression, KNN, decision trees, SVMs, ensembles), unsupervised learning (clustering, dimensionality reduction) and neural networks, to practical pipelines, emerging trends and ML ethics.

Benchmarked against Stanford CS229, MIT 6.867, CMU 10-701, UC Berkeley CS189 and Harvard CS181. Weeks 1–11 have two Beamer decks: Part 1 (core content & assessment pool) and Part 2 (research-article deep-dive & case study). Weeks 12–13 have a single deck each.

Full plans: Theory lecture plan • Lab plan (CSE 814)
